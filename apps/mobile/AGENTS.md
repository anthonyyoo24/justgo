# Expo HAS CHANGED

Read the exact versioned docs at https://docs.expo.dev/versions/v58.0.0/ before
changing code that uses Expo, React Native or native APIs; your training data may
describe an older SDK. Keep this link matched to the installed `expo` version in
`apps/mobile/package.json` and update it in the same change as an SDK upgrade.

Reuse documentation already read in the current working session when the SDK
version and relevant API are unchanged and that context is available. Reread the
relevant versioned sections when the version changes, an unfamiliar API is used
or context is missing. This does not replace required fresh dependency validation
before publication or native/device evidence for affected behavior.

Shared coding and verification standards live in the root [AGENTS.md](../../AGENTS.md).
Keep this file focused on Expo/native requirements.
